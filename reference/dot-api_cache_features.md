# Hydro features (`hydro_short`, `hydro_long`) through the per-fit cache

Same values as
[`.compute_hydro_features()`](https://vorpalvorpal.github.io/hydroSense/reference/dot-compute_hydro_features.md),
as a plain list (no tibble, so it is cheap inside a tau search).

## Usage

``` r
.api_cache_features(cache, target_dates, tau_short, tau_long)
```
